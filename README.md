📊 Employee Attrition & Productivity Analytics

📌 Project Overview  
The Employee Attrition & Productivity Analytics project is an end-to-end data analytics and machine learning solution that analyzes employee attrition trends and workforce productivity using HR data.

This project demonstrates a complete analytics workflow—from data preprocessing and exploratory analysis to attrition prediction and insight visualization. It is designed for Data Analyst and HR Analytics fresher roles and is suitable for a public GitHub repository.

🎯 Problem Statement  
Employee attrition leads to increased hiring costs, productivity loss, and operational instability. Traditional HR reporting often fails to identify early warning signs of attrition and productivity decline.

The objective of this project is to:

- Analyze employee attrition patterns  
- Understand factors affecting workforce productivity  
- Identify high-risk attrition segments  
- Predict employee attrition using machine learning  
- Visualize insights for HR decision-making  

✅ Solution  
The solution uses Python-based data analytics and machine learning to:

- Clean and preprocess HR employee data  
- Perform exploratory data analysis on attrition and productivity  
- Engineer relevant workforce metrics  
- Train a machine learning model to predict attrition risk  
- Present insights using clear and meaningful visualizations  

🧠 Key Features  

- Employee attrition analysis  
- Department-wise and role-based insights  
- Productivity analysis using work hours and performance ratings  
- Attrition risk prediction (Yes / No)  
- Machine learning-based classification  
- Business-friendly HR analytics insights  

🛠️ Tech Stack  

- Programming Language: Python  
- Data Analysis: Pandas, NumPy  
- Visualization: Matplotlib, Seaborn  
- Machine Learning: Scikit-learn (Logistic Regression)  
- Environment: Jupyter Notebook  



🔄 Project Flow  

1. Load and clean employee HR data  
2. Perform exploratory data analysis (EDA)  
3. Analyze attrition trends by department, income, and performance  
4. Prepare features for machine learning  
5. Train a classification model to predict attrition  
6. Evaluate model performance  
7. Generate visual insights for HR decision-making  

📊 Analysis & Insights  

- Attrition rate by department  
- Salary vs attrition trends  
- Performance rating impact on attrition  
- Work hours vs productivity patterns  
- Key factors contributing to employee turnover
